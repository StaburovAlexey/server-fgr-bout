## 🎯 О проекте

Это бэкенд-сервер для моего пет-проекта — браузерной игры, построенной на Pixi.js. Сервер обрабатывает аутентификацию пользователей через Telegram Web Apps, управляет игровыми очками и предоставляет функциональность таблицы лидеров. Как фронтенд-разработчик, исследующий бэкенд-технологии, этот проект служит учебной площадкой для изучения TypeScript и концепций серверной разработки.

## ✨ Возможности

- 🔐 **Аутентификация через Telegram Web App** — безопасный вход с использованием системы аутентификации Telegram
- 👤 **Управление пользователями** — хранение и получение профилей пользователей с уникальными идентификаторами
- 📊 **Отслеживание очков** — постоянное хранение игровых очков в различных режимах игры и главах
- 🏆 **Система таблиц лидеров** — получение лучших игроков по главам и режимам игры
- 🛡️ **Валидация входных данных** — надежная валидация с использованием Zod-схем
- 🗄️ **SQLite база данных** — легкое и эффективное локальное решение для базы данных
- 🚀 **Fastify Framework** — высокопроизводительный веб-фреймворк для Node.js

## 🎮 Фронтенд-репозиторий

Этот бэкенд питает [фронтенд Fixgear Game](https://github.com/StaburovAlexey/fixgear-game), игру на Pixi.js, где игроки решают головоломки и соревнуются в таблицах лидеров.

## 🚀 Деплой

Проект включает скрипт настройки сервера (`server_setup.sh`), который автоматизирует деплой на системах Ubuntu с:
- Конфигурацией обратного прокси Nginx
- Настройкой SSL-сертификатов с Certbot
- Управлением процессами через PM2
- Конфигурацией CI/CD через GitHub Actions

Для продакшен-деплоя рассмотрите использование предоставленного скрипта, который настраивает:
- Среду выполнения Node.js
- Nginx в качестве обратного прокси
- SSL-сертификаты от Let's Encrypt
- PM2 для управления процессами
- Автоматизированные деплои через GitHub Actions

## 📈 Эволюция проекта

Этот проект значительно эволюционировал с момента его создания:

- **Начальная фаза**: Начался как простой сервис аутентификации для поддержки фронтенда игры на Pixi.js

- **Усиление безопасности**: Реализована надежная валидация аутентификации Telegram с правильной проверкой подписи
- **Расширение API**: Разработаны комплексные эндпоинты для профилей пользователей, очков и таблиц лидеров
- **Внедрение тестирования**: Добавлены unit-тесты с Vitest для обеспечения надежности
- **Типизация**: Полная интеграция TypeScript по всей кодовой базе
- **Готовность к продакшену**: Включены скрипты деплоя и конфигурации для продакшен-окружений

Путь разработки отражает исследование фронтенд-разработчиком бэкенд-технологий с акцентом на чистую архитектуру и поддерживаемый код.
